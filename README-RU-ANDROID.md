# «Лента» — сборка Android APK

В архив добавлена Android-оболочка для существующего веб-приложения. Она открывает опубликованный сайт в полноэкранном окне WebView и поддерживает выбор видео/файлов через системный Android-пикер.

## Важно перед сборкой

APK не превращает серверное приложение в полностью автономную программу. Сначала сайт должен быть опубликован по HTTPS, потому что анализ кадров выполняется серверной частью. В проекте также предусмотрен вызов xAI/Grok API: для реального AI-анализа на сервере нужно безопасно настроить переменную `XAI_API_KEY` в окружении хостинга. Не вставляйте этот ключ в Android-код и не передавайте его в APK.

## Сборка через GitHub с телефона

1. Распакуйте архив и загрузите **все файлы и папки проекта** в новый репозиторий GitHub.
2. Опубликуйте веб-проект на Vercel, подключив репозиторий. Если сборка/развёртывание выдаёт ошибку, сначала исправьте её в Vercel. Скопируйте полный HTTPS-адрес опубликованного сайта.
3. В GitHub откройте репозиторий → вкладка **Actions**.
4. В списке workflow выберите **Build Android APK** → **Run workflow**.
5. В поле адреса сайта вставьте адрес из Vercel, например `https://имя-проекта.vercel.app/`, затем нажмите зелёную кнопку запуска.
6. Дождитесь зелёной галочки у завершённого запуска. Откройте его и скачайте артефакт **lenta-android-apk**. Это ZIP-архив, внутри которого находится `app-debug.apk`.
7. На телефоне распакуйте ZIP, откройте `app-debug.apk` и разрешите установку из этого источника, если Android спросит. Устанавливайте APK только из своего репозитория/сборки.

## Сборка на компьютере

Нужны JDK 17, Android SDK (API 35) и Gradle 8.9:

```bash
cd android-app
gradle assembleDebug -PAPP_URL="https://ваш-сайт.vercel.app/"
```

Готовый файл появится в `android-app/app/build/outputs/apk/debug/app-debug.apk`.

## Что делает оболочка

- отображает опубликованный сайт в полноэкранном окне;
- поддерживает JavaScript, cookies и локальное веб-хранилище;
- позволяет выбирать видео и другие файлы из Android;
- кнопка «Назад» возвращает на предыдущую страницу;
- внешние ссылки открываются в браузере.

## Ограничения

- Без опубликованного сайта и реального URL APK не сможет загрузить приложение.
- APK требует интернет для работы сайта и серверного анализа.
- Сборка `debug` подходит для личной установки и тестирования, но не является подписанным релизом для Google Play.
- Прогноз просмотров в приложении — оценка, а не гарантия результата алгоритма TikTok.
